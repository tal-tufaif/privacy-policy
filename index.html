Official Privacy Policy & User Data Disclosure

Privacy Policy for CCCompanion

Extension Name: CCCompanion | Version: 5.1.72 | Publisher: Tayseer Al-Tufaif | Last Updated: November 24, 2026

Overview: CCCompanion is a clinical workflow automation extension for healthcare professionals using authorized Saudi Ministry of Health (MOH) and Eastern Health Cluster (EHC) clinical systems. This Privacy Policy discloses exactly what user data is collected, accessed, handled, stored, and shared—including local browser storage and user-initiated submissions to authorized institutional clinical portals.

1. Single Purpose & Authorized Portals

CCCompanion's single purpose is to streamline repetitive outpatient clinical documentation, e-prescription reorders, and care-coordination workflows directly inside authorized institutional portals:

  • Raqeem Health Information System (HIS): https://moh.raqeem.sa/*, https://raqeem.anat.sa/*
  • Wasfaty E-Prescription Portal: https://pp.wasfaty.sa/*, https://wasfatypp.moh.gov.sa/*
  • Eastern Health Cluster (EHC) Clinical Forms / REDCap: https://tforms.ehc.med.sa/*, https://*.ehc.med.sa/*
  • Authorized Institutional Analytics Dashboards (for clinician right-click National ID lookup & follow-up note entry): http://taamanalytics.ehc.med.sa/*, https://taamanalytics.ehc.med.sa/*, https://metabase.ehcdhn.online/*, https://app.powerbi.com/*

2. User Data Collection

In accordance with the Chrome Web Store User Data Policy, CCCompanion handles and collects the following categories of data solely within the context of authorized clinical sessions and explicit clinician actions:

A. Data Categories Accessed, Processed, or Collected

  • Personally Identifiable Information (PII):
    • 10-digit Saudi National IDs / Iqama numbers detected when a clinician highlights/right-clicks an ID or triggers a quick-search/follow-up action from a patient chart or authorized BI dashboard.
    • This National ID is used strictly to locate the patient record in Raqeem Registration or attach the clinician's follow-up note in the institutional EHC REDCap survey/API.
  • Health Information:
    • Active consultation context displayed inside Raqeem HIS (such as vital signs, lab results, ICD-10 diagnosis codes, patient weight for pediatric dosing checks, and Wasfaty e-prescription reference IDs) read in-memory to render summary tables, clinical trend modals, and medication reorder queues.
    • Clinician-selected medication reorder lists transferred between Raqeem and Wasfaty tabs.
    • Clinician-entered TBC follow-up note data (follow-up status category, optional clinical text remarks, TOT indicator, and submission date) explicitly entered by the user in the TBC Note modal.
  • Website Content:
    • Active DOM text, table structures, form inputs, and same-origin portal API responses (including Raqeem XHR responses for Wasfaty prescription IDs) strictly on the authorized portals listed in Section 1.
  • User Configuration & Custom Macro Presets:
    • Custom ICD-10 note templates and feature toggles configured by the user in the extension Options page (options.html) or imported/exported as local JSON files.

B. Data Categories NOT Collected

  • No Authentication Credentials: CCCompanion does not read, store, or collect user passwords, PINs, OTPs, or portal login tokens.
  • No Financial or Payment Information: CCCompanion does not access or collect credit card, banking, or payment data.
  • No Location Data: CCCompanion does not collect GPS coordinates, geolocation, or IP-based location tracking.
  • No General Web Browsing History or Personal Communications: CCCompanion does not monitor or collect URLs visited outside the authorized portals listed in Section 1, nor does it access emails, chats, or personal communications.
  • No User Activity Tracking / Telemetry: CCCompanion does not log keystrokes, mouse movements, analytics, or usage telemetry.

3. Data Handling & Usage

Every category of user data handled by CCCompanion is processed strictly for its single clinical productivity purpose and in full compliance with the Chrome Web Store Limited Use Policy:

  • In-Page Clinical Formatting & Assistance: Clinical vitals, lab tables, summary column tidying, ICD-10 macro insertion, and weight-based dosage checks execute locally in browser memory on active Raqeem pages.
  • Quick Patient Lookup: When the user selects a National ID and clicks Search in Raqeem, the ID is passed locally via the extension service worker to fill the Raqeem Registration search input in the clinician's authenticated tab.
  • Cross-Tab Wasfaty Order Handoff: When the clinician clicks Reorder in Wasfaty in Raqeem, the selected medication queue is temporarily saved in chrome.storage.local (ccc_wasfaty_order_queue), opened in the clinician's Wasfaty portal tab (pp.wasfaty.sa / wasfatypp.moh.gov.sa), populated into the prescription form, and cleared upon completion.
  • User-Initiated Institutional TBC Note Submission: Only when the clinician explicitly opens the TBC Note modal and clicks Save & Submit (or opens the full survey popup), the extension transmits the National ID, follow-up note code, optional remarks, TOT indicator, and date via HTTPS POST directly to the authorized institutional EHC REDCap API (https://tforms.ehc.med.sa/api/). No automatic background uploads occur without explicit user submission.
  • Prohibited Uses: Data is never used for personalized advertising, marketing, creditworthiness evaluation, data brokering, or training external AI models.

4. Data Storage, Retention, and Deletion

  • Local Device Storage (chrome.storage.local & page localStorage):
    • User preferences and custom ICD-10 presets (cccompanionCustomMacros, cccCommunityScreening, cccSymptomsSuggestion, cccShowAiAssistant, cccTidyColumns) remain stored locally on the user's computer until edited or deleted by the user.
    • Temporary Wasfaty medication handoff payloads (ccc_wasfaty_order_queue) are stored transiently in chrome.storage.local only during transfer between Raqeem and Wasfaty and are automatically removed once consumed or cancelled.
    • Users can modify or delete saved templates at any time in options.html, or uninstall CCCompanion to permanently purge all local extension storage.
  • Institutional Server Storage (EHC REDCap):
    • TBC follow-up note records explicitly submitted by the clinician are stored within the Eastern Health Cluster REDCap database (tforms.ehc.med.sa) in accordance with EHC and Saudi Ministry of Health institutional data governance and medical record retention policies.
    • The developer does not maintain any personal or independent third-party cloud database or server infrastructure.

5. Data Sharing & All Third Parties

Comprehensive List of All Parties User Data May Be Shared With or Transferred To:

  • 1. Eastern Health Cluster (EHC) / Saudi Ministry of Health Institutional REDCap System (https://tforms.ehc.med.sa/): Receives user-submitted TBC clinical follow-up note records (National ID, follow-up note selection, optional remarks, TOT flag, and date) exclusively when a clinician explicitly triggers a TBC Note submission.
  • 2. Authorized Clinical Portals Operated by the User's Institution (moh.raqeem.sa, raqeem.anat.sa, pp.wasfaty.sa, wasfatypp.moh.gov.sa): User-initiated actions (such as searching a patient National ID or populating a Wasfaty medication reorder) pass data directly into the clinician's own authenticated browser session on these institutional portals.
  • 3. Commercial Third Parties, Advertisers, Data Brokers, Analytics Vendors, or Unrelated External Servers: NONE. CCCompanion does not sell, rent, trade, or share user data with any advertising platforms, analytics providers, data brokers, or unauthorized third parties.

6. Permissions & Host Access Justification

  • storage: Saves custom clinical macro presets and feature toggles locally (chrome.storage.local) and temporarily stages Wasfaty medication reorder queues between Raqeem and Wasfaty tabs.
  • contextMenus: Adds right-click context menu shortcuts ("Search in Raqeem" and "Fill TBC Note") for selected 10-digit National IDs.
  • tabs: Detects or opens authorized Raqeem and Wasfaty browser tabs to execute clinician-triggered patient searches and e-prescription transfers.
  • Host Permissions (moh.raqeem.sa, raqeem.anat.sa, pp.wasfaty.sa, wasfatypp.moh.gov.sa, tforms.ehc.med.sa, app.powerbi.com) & Content Script Origins (*.ehc.med.sa, taamanalytics.ehc.med.sa, metabase.ehcdhn.online): Required to render workflow UI helpers inside Raqeem/Wasfaty, capture selected National IDs on authorized BI dashboards, handle EHC survey popups, and transmit user-initiated TBC notes to the EHC REDCap API.

7. Security & User Consent

  • Prominent Disclosure & Affirmative Consent: Before installation, all data handling practices are prominently disclosed in the Chrome Web Store listing and this Privacy Policy. Inside the extension, external data transmissions (TBC Note submission to EHC REDCap, Wasfaty order transfer, and Raqeem ID lookup) occur only upon explicit, affirmative clinician action (clicking the action button or context menu command).
  • Transport Encryption: All communications with authorized institutional endpoints (including https://tforms.ehc.med.sa/api/) are encrypted over HTTPS/TLS with credentials: 'omit'.
  • No Remote Code: CCCompanion does not load or execute remote JavaScript, eval(), or external WebAssembly. All executable code is bundled inside the verified extension package.

8. Chrome Web Store Limited Use Compliance

The handling and use of all user data received or processed by CCCompanion strictly adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements, as well as the Microsoft Edge Add-ons Developer Policies.
